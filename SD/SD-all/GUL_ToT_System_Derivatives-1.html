Layer 0 — GUL Primitives

The irreducible base from which all structures are derived. Nothing below this layer imports classical results.

Primitive

State Space $\mathcal{G}$

$$S = (s_1, s_2, \ldots, s_n) \in \mathcal{G}$$
Axiom G1 — Manifold Structure
$\mathcal{G}$ is equipped with a smooth differentiable structure. For every $s \in \mathcal{G}$, the tangent space $T_s\mathcal{G}$ and cotangent space $T_s^*\mathcal{G}$ exist. The dual space $\mathcal{G}^*$ is defined as the space of linear functionals on $\mathcal{G}$, and momenta are elements of $\mathcal{G}^*$: $$P_i \in \mathcal{G}^*$$ In the discrete-ToT case, this is replaced by a discrete metric embedding: $$d: \mathcal{G} \times \mathcal{G} \to \mathbb{R}_{\geq 0}$$ with all derivative operators defined in terms of $d$ (see Axiom D below).
Primitive

Transition Operator $T$

$$T: S \mapsto S' = f_T(S)$$

Maps a GUL state to its successor. In ToT trees, $T$ is the branch evaluation function.

Primitive

Action Functional $A[S]$

$$A[S] = \int_{t_0}^{t_f} \mathcal{L}_{\text{GUL}}(S, \dot{S}, t)\, dt$$

Cumulative path cost over a trajectory in $\mathcal{G}$. In ToT, this is the cumulative scoring functional along a reasoning path.

Axiom

Axiom D — GUL Derivative Operator

The semantic derivative operator $D$ is defined internally on $\mathcal{F}(\mathcal{G})$ (the space of functionals over $\mathcal{G}$):

Continuous case:

$$D[f](S) := \lim_{\epsilon \to 0} \frac{f(T_\epsilon(S)) - f(S)}{\epsilon}$$
where $T_\epsilon$ is the incremental evolution operator over semantic state $S$.

Discrete case (canonical for ToT trees):

$$D[f](S_n) := f(S_{n+1}) - f(S_n), \qquad S_{n+1} = T(S_n)$$
Axiom D-P — Canonical Momentum via D
$$P_i := D[L_{\text{der}}] / D[\dot{s}_i] = \frac{\partial L_{\text{der}}}{\partial \dot{s}_i} \in \mathcal{G}^*$$ $P_i$ measures sensitivity of the action functional to perturbations in the $i$-th thought transition rate. Fully internal; no free variable.
Axiom

Axiom $\dot{S}$ — Semantic Velocity / Inner Product

For discrete ToT states, define the semantic inner product:

$$\langle S_n,\, S_{n+1} \rangle := \sum_i d(s_i^{(n)},\, s_i^{(n+1)})^2$$

The kinetic term in $L_{\text{der}}$ becomes:

$$\mathcal{T}(S_n, S_{n+1}) := \tfrac{1}{2}\,\langle S_{n+1} - S_n,\; S_{n+1} - S_n \rangle$$

This resolves $\dot{S}$ for discrete trees without requiring continuous embedding. $\text{Ld\_der}$ operates directly on $(S_n, S_{n+1})$ pairs and is therefore the natural integrator for ToT dynamics.

Layer 1 — Primary Formalisms

Derived directly from GUL primitives via internal axioms. Each arrow in the derivation chain is replaced by an explicit internal rule — no classical theorem is borrowed.

L_der

Lagrangian Mechanics

$$L_{\text{der}}(S) := \mathcal{L}_{\text{GUL}}(S,\, \dot{S},\, t)$$

Euler–Lagrange equations as a ToT derivative:

$$\forall\, i:\quad D_t\!\left[\frac{\partial L_{\text{der}}}{\partial \dot{s}_i}\right] - \frac{\partial L_{\text{der}}}{\partial s_i} = 0$$
Internal Rule L→H (Legendre Existence)
For any $L_{\text{der}}(S) \in \mathcal{F}(\mathcal{G})$, there exists a dual functional $H_{\text{der}}(S, P) \in \mathcal{F}(\mathcal{G} \times \mathcal{G}^*)$ such that: $$H_{\text{der}}(S, P) = \sum_i P_i \dot{s}_i - L_{\text{der}}(S)$$ This axiom replaces the classical Legendre transform existence theorem. It is an internal statement about $\mathcal{G}$ and $\mathcal{G}^*$.
H_der

Hamiltonian Mechanics

Canonical momenta projected from $L_{\text{der}}$:

$$P_i := D[P_i](S) = \frac{\partial L_{\text{der}}}{\partial \dot{s}_i} \in \mathcal{G}^*$$

Hamiltonian as Legendre transform over GUL state:

$$H_{\text{der}}(S, P) := \sum_i P_i \dot{s}_i - L_{\text{der}}(S)$$

Equations of motion:

$$\dot{s}_i = D[s_i](H_{\text{der}}) = \frac{\partial H_{\text{der}}}{\partial P_i}, \qquad \dot{P}_i = D[P_i](H_{\text{der}}) = -\frac{\partial H_{\text{der}}}{\partial s_i}$$
HJ_der

Hamilton–Jacobi

HJ action scalar renamed $\Phi_{\text{HJ}}$ to eliminate symbol collision with the state vector $S$:

$$\Phi_{\text{HJ}}(S, t) := D[\text{HJ}](\mathcal{G}) \quad \text{(scalar functional over GUL state)}$$

Hamilton–Jacobi equation:

$$\frac{\partial \Phi_{\text{HJ}}}{\partial t} + H_{\text{der}}\!\left(S,\; \frac{\partial \Phi_{\text{HJ}}}{\partial S}\right) = 0$$

Momentum projection:

$$P_i = \frac{\partial \Phi_{\text{HJ}}}{\partial s_i} \in \mathcal{G}^*$$
Notation Fix Applied
$S_{\text{HJ}}$ has been renamed $\Phi_{\text{HJ}}$ throughout. $S$ is reserved exclusively for the GUL state vector. All ambiguity is resolved.

Layer 2 — Derived Structures

Built from Layer 1 formalisms. Require additional axioms or preconditions stated explicitly below each entry.

PB_der

Poisson / Symplectic Mechanics

Axiom SP — Symplectic Coordinates
There exists a canonical Poisson bracket on $\mathcal{G} \times \mathcal{G}^*$ satisfying: (i) antisymmetry: $\{f, g\}_{\text{der}} = -\{g, f\}_{\text{der}}$; (ii) Leibniz rule: $\{f, gh\}_{\text{der}} = g\{f,h\}_{\text{der}} + h\{f,g\}_{\text{der}}$; (iii) Jacobi identity: $\{f,\{g,h\}\} + \{g,\{h,f\}\} + \{h,\{f,g\}\} = 0$. This replaces the classical Darboux theorem; it is an internal axiom on $\mathcal{G}$.

Bracket operator, fully internal to $\mathcal{G}$:

$$\{f,\, g\}_{\text{der}} := \sum_i \left(\frac{\partial f}{\partial s_i}\frac{\partial g}{\partial P_i} - \frac{\partial f}{\partial P_i}\frac{\partial g}{\partial s_i}\right)$$

Time evolution of any functional:

$$\dot{f} := D[f](\mathcal{G}) = \{f,\, H_{\text{der}}\}_{\text{der}} + \frac{\partial f}{\partial t}$$
AA_der

Action-Angle Variables

Precondition — Liouville–Arnold (ToT-Native)
$\text{AA\_der}$ exists if and only if there exist $n$ independent functionals $F_1, \ldots, F_n \in \mathcal{F}(\mathcal{G})$ in involution: $$\{F_i,\, F_j\}_{\text{der}} = 0 \quad \forall\, i, j$$ This replaces the classical Liouville–Arnold theorem with a ToT-native existence condition. When this precondition does not hold, $\text{AA\_der}$ is undefined.

Canonical transformation derived from $(S, P)$:

$$(I,\, \theta) := D[\text{AA}](S,\, P)$$

Under this transformation, $H_{\text{der}}$ depends only on action variables:

$$H_{\text{der}} = H_{\text{der}}(I), \qquad \dot{I} = 0, \qquad \dot{\theta} = \frac{\partial H_{\text{der}}}{\partial I}$$
Nambu_der

Nambu Mechanics

Conjecture — Pending Conserved Functionals
Nambu mechanics requires two independent conserved functionals $H_1, H_2 \in \mathcal{F}(\mathcal{G})$ in involution: $$\{H_1,\, H_2\}_{\text{der}} = 0$$ This structure is conjectural within ToT until specific conserved functionals are constructed over the semantic state space $\mathcal{G}$. Once identified, full Nambu dynamics follow.

Multi-bracket operator over $\mathcal{G}$:

$$\{F,\, G,\, H\}_{\text{der}} := \sum_{ijk} \epsilon_{ijk}\, \frac{\partial F}{\partial s_i}\frac{\partial G}{\partial s_j}\frac{\partial H}{\partial s_k}$$

Generalized equations of motion:

$$\dot{s}_i := D[s_i](\mathcal{G}) = \{s_i,\, H_1,\, H_2\}_{\text{der}}$$
Ld_der

Discrete / Variational Integrator

Discrete Lagrangian functional over adjacent GUL states:

$$L_{d,\text{der}}(S_n,\, S_{n+1}) := D[L_d](S_n,\, S_{n+1})$$

Discrete Euler–Lagrange equations (variational integrator):

$$D_2\, L_{d,\text{der}}(S_{n-1},\, S_n) + D_1\, L_{d,\text{der}}(S_n,\, S_{n+1}) = 0$$
Note — Natural ToT Integrator
$\text{Ld\_der}$ is the most natural dynamics law for ToT trees: it operates directly on $(S_n, S_{n+1})$ pairs, requires no continuous embedding, and inherits symplectic structure from PB_der. It is the preferred integrator for all discrete semantic dynamics.
